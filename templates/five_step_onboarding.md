# Five-step Agent Manager onboarding

1. **Project Map** — one Setup Agent chat maps the entire umbrella ChatGPT Project and returns `chatgpt_project_map` JSON.
2. **App Deep Audit** — the same Setup Agent deeply audits the selected app and returns `selected_app_audit` JSON.
3. **Director / Organization** — Director designs the project-specific agent organization and returns `director_organization_plan` JSON.
4. **Features / Plan** — Director builds the durable feature board and first cycle in `director_feature_plan` JSON.
5. **Agent Setup** — Prompt Agent refines stable role contracts into `agent_bootstrap_pack` JSON; the human creates/links the actual chats and records model labels.

Use stable IDs and explicit unknowns. Do not invent chat URLs, Git state, model entitlements, tests or deployments.
