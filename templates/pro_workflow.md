# Pro advisory workflow

1. Open **Pro Desk → Ask Liaison** and copy the deterministic Liaison request into the Liaison chat.
2. The Liaison reconciles the project/run/Git state and returns one standalone prompt for the Pro Advisor.
3. Paste that prompt into **Pro Desk → Send to Pro**, then use **Copy + Open Pro**.
4. Paste the Pro answer into **Pro Desk → Return to Director**.
5. The app wraps the answer with project/run metadata and a Director handling contract. Send that packet to Director.

The Pro Advisor is advisory. Director remains responsible for reconciling advice against the pinned project constraints and actual evidence.
